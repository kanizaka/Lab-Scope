Lab-Scope
https://kanizaka.github.io/Lab-Scope/
Lab-Scope is a comprehensive laboratory reference application that provides healthcare professionals, laboratory scientists, biomedical engineers, and medical students with quick access to normal laboratory reference ranges and essential clinical information.

The application serves as a portable laboratory handbook, helping users interpret laboratory values efficiently while improving workflow in hospitals, clinics, and diagnostic laboratories.

✨ Features

* 📚 Extensive database of laboratory reference ranges
* 🩸 Hematology (CBC, ESR, Blood Film)
* 🧪 Clinical Chemistry
* 🧬 Immunology & Serology
* 🦠 Microbiology
* 🧫 Endocrinology & Hormones
* ❤️ Cardiac Biomarkers
* 🧠 Tumor Markers
* 🩺 Coagulation Tests
* 💧 Urinalysis
* 🧬 Molecular & Genetic Tests
* 👶 Pediatric and adult reference values where applicable
* 🔍 Fast search for any laboratory test
* 📱 Clean, modern, and mobile-friendly interface
* 🌐 Offline access to laboratory reference data

🎯 Purpose

Lab-Scope is designed to provide a fast, reliable, and easy-to-use laboratory reference resource, enabling healthcare professionals to quickly verify normal reference ranges and better understand laboratory investigations in clinical practice.

👨‍⚕️ Intended Users

* Physicians
* Clinical Laboratory Scientists
* Biomedical Engineers
* Medical Students
* Nurses
* Healthcare Professionals

⚠️ Disclaimer

Reference ranges may vary depending on the laboratory, patient age, sex, methodology, and equipment used. Always refer to your local laboratory’s validated reference intervals when making clinical decisions.
